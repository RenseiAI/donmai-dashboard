# donmai-dashboard (retired)

**This deployment is retired as of 2026-10-19, and the repository is archived (read-only).**

It used to serve the hosted fleet dashboard at `dashboard.donmai.dev`, reached via
`donmai.dev/dashboard` and the legacy `agent.rensei.dev` / `agent.supaku.dev` hosts.

- Hosted fleet management now lives in the Rensei platform: https://app.rensei.ai
- The open-source execution layer is the Go `donmai` binary: https://donmai.dev
- `donmai.dev/dashboard/*` now redirects to the donmai.dev home page.

The Vercel project is paused, not deleted, and the domain and DNS records are left
in place, so the retirement can be undone. Nothing in this repository is maintained.
